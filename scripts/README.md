# ⚙️ DermaVision `scripts/` Automation & Operational Tools

This directory provides maintenance, health-check, deployment, and operational scripts for DermaVision.

---

## 📂 Scripts Directory

| Script | Type | Description |
| :--- | :--- | :--- |
| `run_diagnostics.py` | Python | Complete subsystem verification: MediaPipe, Ollama, Free Maps API & packages |
| `start_server.bat` | Batch | Launches the local Streamlit application server |
| `install_dependencies.bat` | Batch | Automated pip environment installation |

---

## 🚀 Running Subsystem Diagnostics

Run from repository root:

```bash
python scripts/run_diagnostics.py
```
